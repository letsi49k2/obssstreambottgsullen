## 🕹 obssstreambottgsullen: Твой карманный микрооный дережер

**obssstreambottgsullen** — это мощный инструмент для удаленного управления твоим игровым местом и стримом прямо через Telegram. Забудь о сворачивании игр или поиске нужных окон: теперь всё управление звуком, камерами и мультимедиа находится в твоем телефоне.

### 🚀 Основные возможности:

* **🎙 Управление микрофонами:** Мгновенное переключение между девайсами (например, с основной гарнитуры на студийный микрофон) одной кнопкой.
* **📸 Интеграция с OBS:** * Управление «Глазиком» (включение/выключение источников).
    * Запуск и остановка виртуальной камеры.
    * Проверка статуса подключения.
* **🖼 Контроль в реальном времени:**
    * **Скриншот ПК:** Получай снимок основного монитора, чтобы проверить, что происходит на экране.
    * **OBS Preview:** Прямой захват текущей активной сцены из OBS — узнай, что видят зрители, не отвлекаясь от игры.
    * *Безопасность:* Все скриншоты автоматически удаляются из чата через 60 секунд.
* **🎵 Музыкальный пульт:**
    * Отдельное управление для **Spotify Free** (Play/Pause, Next Track) — работает даже в свернутом режиме!
    * Общая системная кнопка Play/Pause для браузеров и других плееров.
* **⌨️ Системные команды:** Быстрое переключение окон через Alt+Tab.
* **🤖 Работа в фоне:** Бот сворачивается в системный трей (рядом с часами), не мешает работе и всегда готов к командам.

### 🛠 Технологии:
Бот построен на базе **Python 3**, использует современные библиотеки `aiogram`, `pywin32` для системного контроля и `obs-websocket` для связи с твоей студией.

---

### 💡 Как начать пользоваться:
1. Запусти серверную часть бота на своем ПК.
2. Открой Telegram и нажми **/start**.
3. Наслаждайся полным контролем над своим стримом из любой точки комнаты!

> *Разработано специально для стримеров, ценящих комфорт и скорость.*
